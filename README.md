# 网页 NES 模拟器

基于 [EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) 的网页版 NES 模拟器，部署在 GitHub Pages 上，开箱即玩。

- 🎮 内置 25 款免费 homebrew / 公有领域 NES 游戏（`roms/` 目录 + `games.json` 游戏库）
- 📁 支持上传本地 `.nes` 文件直接游玩（文件仅在浏览器本地运行，不上传服务器）
- 🔍 游戏库支持按名称/类型/作者搜索、按类型筛选
- 📱 自带触屏手柄，手机也能玩；支持存档（浏览器本地）
